<summary>Project notes & more open source</summary>

- [tanuki-context](https://github.com/Osyna/tanuki-context): renders logs and command output as dense image pages or stores them for retrieval by slice. Its published evaluation reports 79–91% token savings on compressible inputs. It prices each strategy against the target model and keeps plain text when that is cheaper. Zero runtime dependencies.
- [Macaw](https://github.com/Osyna/Macaw): hot-swappable speech-to-text engines, including Whisper, Moonshine and Parakeet. CUDA decode with ROCm/CPU fallback; backends run in separate environments.
- [QuestionAir](https://github.com/Osyna/QuestionAir): LLaMA via Ollama, embedding-based keyword extraction, French checks through spaCy. FastAPI, Pydantic and SQLite behind Next.js.
- [Tiingo-python](https://github.com/Osyna/Tiingo-python): EOD, IEX intraday, crypto, FX and fundamentals, with full annotations and httpx.
- [RadiAll](https://github.com/Osyna/RadiAll): a Rust radial application launcher for Wayland.
- [Pinna](https://github.com/Osyna/Pinna): a self-hostable alternative to Mapstr, built with Vue.

Also [QML](https://github.com/Osyna/QML), [AzureBlobStorageExplorer](https://github.com/Osyna/AzureBlobStorageExplorer), [GrafanaPrometheus_4_Coolify](https://github.com/Osyna/GrafanaPrometheus_4_Coolify), [YTM-Player](https://github.com/Osyna/YTM-Player) and [Dot.Files](https://github.com/Osyna/Dot.Files).

<summary>How this profile stays up to date</summary>

The [nightly workflow](./.github/workflows/pulse.yml) refreshes the latest original projects (newest by creation date, excluding forks and archived repositories), counters, repository stars and forks, contribution calendar, npm download chart, and animated headers. The calendar comes from GitHub's public contribution page; downloads come from npm's reported interval, which may lag today. Counts are snapshots, not real-time widgets.

The mountain scene is drawn in [SVG](./scripts/art.mjs) and rendered into two looping six-second GIFs, sized for desktop and mobile. The aurora drifts above the peaks, stars shimmer, and mist moves through the valley; text stays still. Browsers requesting reduced motion receive a still SVG instead. Latest and featured projects use linked, text-only cards arranged without HTML tables, so GitHub adds no table borders.

[The renderer](./scripts/render.mjs) uses Node.js 22 and the pinned development dependency `sharp` for SVG rasterization and GIF encoding. Local rendering also needs Fontconfig and a sans-serif font (`fontconfig fonts-dejavu-core` on Debian/Ubuntu). Published assets need no server or external image host.

To check and refresh locally:

```sh
npm ci
npm test
npm run render
```

An optional `GH_TOKEN` raises the GitHub API rate limit; it is sent only to `api.github.com`. Data validation, README marker checks, and GIF rendering complete before published files are written. Failed requests or malformed data leave the published panels intact. If GitHub changes its public calendar markup, the parser may need an update.

</details>
